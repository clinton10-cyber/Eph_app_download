Setup

Install in under a minute

Android

  1. Tap Download APK and wait for it to finish.
  2. Open the file from your notifications or Downloads.
  3. If asked, allow Install unknown apps for your browser.
  4. Tap Install, then open Everyday in PH.

Windows

  1. Download the Installer (or the Portable file).
  2. Double-click the file you downloaded.
  3. If SmartScreen appears, click More info then Run anyway.
  4. Finish setup and launch from the Start menu or desktop.
FAQ

Good to know

Is it really free?

Yes. Download, install and play for free.

Why does my phone warn me about the APK?

Android shows a warning for any app installed outside the Play Store. The file is built automatically on GitHub from the game's source code, and you can compare it with the release page.

What is the difference between Installer and Portable?

The installer adds the game to your Start menu and can be uninstalled normally. The portable file runs on its own from any folder, with nothing to install.

What is the Debug APK?

A larger build meant for testing. Most people should use the normal APK.

Will my progress be kept when I update?

Install the new version over the old one, without uninstalling first, so your saved game stays in place.
